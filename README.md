# Augustin's YouTube Thumbnail Filter

A "filterless filter" designed to unlock a distraction-free YouTube experience using uBlock Origin. This filter completely removes video thumbnails and the empty space they leave behind, turning YouTube into a clean, text-only feed. 

## Features
- Zero Thumbnails: Hides thumbnails on the home page, search results, and sidebar.
- Collapses Space: Adjusts the layout spacing so video titles stack cleanly without awkward gaps.
- Lightweight: Uses native uBlock Origin element hiding and CSS injection.

## How to Install (Subscribe)
1. Open the uBlock Origin dashboard (click the extension icon, then click the gears icon).
2. Go to the Filter lists tab.
3. Scroll to the very bottom and check the box for Import...
4. Paste the raw URL of the filter list:
   `https://raw.githubusercontent.com/iamaugustinthomas/Augustin-s-YouTube-Thumbnail-Filter/refs/heads/main/augustin_ytt_filter.txt`
5. Click Apply changes in the top left.

## How to Install (Manual Paste)
If you just want to test it quickly:
1. Open the uBlock Origin dashboard.
2. Go to the My filters tab.
3. Copy the contents of `augustine-filter.txt` and paste them into the text box.
4. Click Apply changes.
